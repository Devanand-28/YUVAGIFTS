# 🎁 Yuvagifts

Gift shop website with WhatsApp ordering and an admin dashboard.

## Structure
- `index.html`, `products.html`, `contact.html`, `login.html`
- `admin-login.html`, `admin-dashboard.html`
- `css/style.css` · `js/main.js` (data, navbar/footer, auth) · `js/products.js` · `js/admin.js`

## Run
Keep the folder structure and open `index.html`. No server needed.

## Admin demo login
`admin` / `admin123` (demo only; client-side, not secure)

## WhatsApp orders
"Order on WhatsApp" opens a pre-filled message to +91 8637604442. Change `WHATSAPP_NUMBER` in `js/main.js`.
